How it works

Everything is a plugin, and every plugin states its trust rules in code. Muse proposes, code verifies, a person releases.

LIST

Muse lists every claim, word for word. It fixes nothing.

POINT

Muse points to where the filing reports it. It never sees the memo's number.

READ

Code reads the PDF's own text and gives the verdict. Muse has no vote.

RELEASE

Every number must match. Then a person approves.
